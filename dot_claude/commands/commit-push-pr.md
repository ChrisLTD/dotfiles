If we're on main/master, suggest creating a feature branch first.

Run typechecks, format checks, builds, and linter. Once that's good, create a commit, push to remote, and open a pull request for the current changes.

Open the PR in draft mode. Keep the PR description concise. No em dashes in the title or description.

Use the PR template from CLAUDE.md or AGENTS.md if available.
